<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Payload path -> filesystem | `crop_ref`, `crop_path`, or `payload_uri` from local JSON can point anywhere unless constrained. |
| Dashboard display -> judge trust | Rendering a raw/source image would falsely imply it was downlinked. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Spoofing | Crop preview | mitigate | Resolve and render only queue/downlinked crop paths; show `no real crop available` otherwise. |
| T-02-02-02 | Information Disclosure | Raw/source imagery | mitigate | Reject forbidden raw/source paths and add static tests across dashboard modules. |
| T-02-02-03 | Tampering | Payload crop path | mitigate | Treat crop paths as untrusted local artifact references and normalize against queue root. |
</threat_model>
