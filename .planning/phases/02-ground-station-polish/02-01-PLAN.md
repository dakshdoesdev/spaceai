<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Queue payload/telemetry -> dashboard | Local JSON/JSONL artifacts drive user-visible proof status and crop evidence. |
| Crop path -> Streamlit image renderer | A payload path becomes a file read and browser-visible image only if helper logic marks it safe. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01-01 | Spoofing | Proof Status panel | mitigate | Display raw truth fields and explicit labels for detector/reasoner state; tests cover mock vs real labels. |
| T-02-01-02 | Information Disclosure | Crop Review panel | mitigate | Render only queue/downlinked crop evidence and rely on helper checks to block raw/source paths. |
| T-02-01-03 | Tampering | Payload metadata | accept | Local demo artifacts are trusted enough for display, but labels remain advisory and do not claim enforcement certainty. |
</threat_model>
