Transmission Queue

the only boundary the ground station can see

transmission_queue/

The ground station reads only these artifacts. Raw tiles never cross the satellite boundary. Bandwidth savings come from real byte accounting against onboard tile sizes.
Liquid annotates the evidence. YOLO + the four-tier triage decide the gate. LFM2-VL reasons over the crop after detection — never the raw tile.
Pipeline: raw tile → YOLO bbox → real crop → Liquid structured JSON → four-tier gate → downlink → queue → this dashboard.
